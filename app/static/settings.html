Kindle

Find it on Amazon under Manage Your Content and Devices → Preferences → Personal Document Settings. On the same page, add your Gmail address to the Approved Personal Document E-mail List.

Gmail (sends the books)

Use an app password, not your normal password. It needs 2-step verification turned on.

Not using Gmail?

Result emails

After each book you get an email saying whether it worked.

Google Drive folder (optional)

New files added to this folder are sent to your Kindle automatically. The README explains how to create the service account key.

Advanced

Libby (optional)

Watches your Libby account. Ready holds are borrowed, and new ebook loans are sent to your Kindle. Loans you already have when you connect are skipped; send them from the main page if you want them. It signs in with your library card, so it sees the same loans and holds as the Libby app.

Adobe device

A one-time step that lets this server open library loans.

Use an Adobe ID instead of anonymous (optional)
